# Power-BI-Job-Satisfaction
A simple dashboard created in Power BI to practice data cleaning and data shaping using the Power Query Editor

For this exercise, I followed a YouTube tutorial and used data on employee satisfaction 
and attrition levels from a fictional company to build a dashboard 
showcasing insights into employees' socio-demographic characteristics 
and their respective departments.
